# Pharmacy Ordering System

A simple Pharmacy Management System built with **Java Swing**.

## Features

- Set pharmacy capacity at startup
- Add new drugs (ID, Category, Price, Quantity)
- Remove drugs by ID
- Place orders with quantity validation
- Calculate total sales of the day
- Real-time display of available drugs

## Categories Supported
- Cosmetics (price increased by 20%)
- Prescription drugs
- Other

## How to Run

1. Make sure you have **Java JDK** installed.
2. Open the project in NetBeans, IntelliJ, or VS Code.
3. Run the `Main` class.
